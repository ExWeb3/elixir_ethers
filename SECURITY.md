# Security Policy

## Supported Versions

Security fixes are released as new 1.x versions. Versions before 1.0 do not receive them.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately through
[GitHub's vulnerability reporting](https://github.com/ExWeb3/elixir_ethers/security/advisories/new),
or by email to alisina.bm@gmail.com.
